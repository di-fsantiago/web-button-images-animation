# web-button-images-animation
Manipulação dinâmica e animada de imagens através de botões. A página alterna entre imagens de comemoração do título da Libertadores dos quatro grandes times paulistas.

## 02. Tecnologias Utilizadas
- HTML5
- CSS3
- Javascript 

## 03. Como Instalar e Executar
Não é necessário instalar nenhuma dependência.

1. Clone este repositório:
   ```bash
   git clone https://github.com/di-fsantiago/web-button-images-animation.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd web-button-manipulation/atividade-libertadores
   ```

3. Abra o arquivo `index.html` em seu navegador.

## 04. Exemplo de Uso ou Demonstração
Ao abrir a página (index.html), você encontrará os seguintes botões interativos:
* 2012 (Corinthians)
* 2021 (Palmeiras)
* 2011 (Santos)
* 2005 (São Paulo)

**Recursos Visuais:**
> Ao clicar em qualquer botão, a foto muda com um efeito dinâmico de aparecimento (fade-in / scale).
>
> Ao passar o mouse sobre a foto (hover), a imagem expande para destaque.
